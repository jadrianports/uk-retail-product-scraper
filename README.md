# UK Retail Product Scraper

This tool captures product attributes for one category from a UK retailer
website. It writes the data to CSV and to JSON. It gives one row for each
product and one column for each attribute.

The first target is the gin category at Morrisons.

## Status

The project is in progress. This README grows with the code.
